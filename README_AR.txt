# GOLD RAIN - Android build starter

هذا مشروع تجهيز أولي لبناء نسخة APK من لعبة GOLD RAIN باستخدام Pygame CE وBuildozer.

## مهم قبل البناء
- ملف `main.py` هو نسخة اللعبة مع دعم أحداث اللمس المباشرة (Finger events).
- لا يحتوي هذا الملف على APK جاهز. البناء يحتاج بيئة Linux/CI واتصال إنترنت.
- وصفة Pygame CE المرفقة تجريبية ومجتمعية وليست جزءًا رسميًا مضمونًا من python-for-android.
- قد يفشل البناء أو يحتاج تحديثًا للوصفة/إصدارات SDL وPygame. يجب اختبار APK على جهاز أندرويد قبل إرساله للأصدقاء.
- قد تختلف جودة الصوت أو بعض خصائص Pygame على أندرويد.

## البناء من الموبايل عبر GitHub Actions
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد كاملة.
2. افتح تبويب Actions في المستودع.
3. وافق على تفعيل Actions إذا طُلب منك.
4. اختر `Build GOLD RAIN APK` ثم `Run workflow`.
5. عند اكتمال البناء، افتح نتيجة التشغيل ونزّل artifact باسم `GOLD-RAIN-APK`.
6. فك ضغط الملف، وستجد APK إذا نجح البناء.

## بعد تنزيل APK
جرّبه أولًا على هاتفك. إذا اشتغل بشكل صحيح، أرسله كـ Document على واتساب حتى لا يضغطه واتساب كصورة/فيديو.
